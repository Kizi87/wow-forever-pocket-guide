# Product brief — WoW Forever Pocket Guide

## One line

A phone-friendly companion that reads Kiz's pasted character export and tells Chris what to do next to reach level 60 smoothly: quests, dungeons, gear, professions — with every game fact sourced and honestly labelled.

## User

One person: Chris. Plays on PC, checks the phone between pulls. Experienced WoW player, new to Forever's changes. Values verified information and minimal wasted travel. Single character for now (Kiz), designed so a second character could be added later.

## Core loop

1. In game: run ForeverCharacterExport (out of combat), copy.
2. On phone/PC: open the app, paste.
3. App parses, saves a snapshot, shows **what changed** and **what to do now**.
4. Chris ticks things off, adds notes, marks facts wrong when the game disagrees.

## MVP (milestone 1–3)

### M1 — Import and character view
- Paste box → parser (see `export-format.md`) → snapshot stored in IndexedDB.
- Character page: level/XP bar, gold, location, hearth, gear by slot (empty slots highlighted), talents, professions with caps, weapon skills (warn when skill is far below cap for the equipped weapon type), bags/bank summary.
- Snapshot history + diff between latest two.
- Fixture tests against both sample exports.
- Backup: export/import all app data as JSON.

### M2 — Quest tracker
- Quest log from the latest snapshot, grouped: Ready to turn in · Do now · Dungeon · Hold (too high) · Consider abandoning (grey).
- Grouping by level difference (configurable thresholds) and by zone so Chris can plan a trip ("I'm going to Thousand Needles — what's there?").
- Per quest: objectives with progress, Chris's notes, knowledge from `data/quests/*.json` (giver, turn-in, where, tips) **with confidence badges**; link out to Wowhead Forever page by ID.
- Seed data from `docs/knowledge/quest-status.md`.

### M3 — "Now" screen and Paladin guide
- "Now": top 3–5 actions, generated by simple rules from the snapshot + data (turn-ins nearby, profession cap reached, train new ranks at even levels, empty gear slots, weapon skill low, quests gone grey, dungeon in range).
- Optional time box: "I have 45 minutes" → filter to actions that fit (idea from classicwowforever.dev).
- Paladin page: Forever Ret rotation, macros, talent plan to 60 (shows current vs suggested; flag where guides conflict), what to train next level.
- Dungeon cards: level range (all conflicting ranges shown), quests to grab before going, access requirements (e.g. Dalaran key chain + level 30), boss notes, known bugs.

## Later (milestone 4+)
- Professions: Blacksmithing and Mining progress, "reach skill X" planner using materials in bags + bank, trainer reminders at 50/125/200 + level gates, Legacy points, camp objects.
- Gear: compare equipped items, slot wishlist (e.g. Martyr's Chain from BFD), upgrade ideas by level band from a Forever item dataset.
- Levelling route suggestions by zone for Horde 30–60 (Forever-new zones like Riverglades included once data exists).
- Report-a-fact queue: facts Chris marked wrong, to re-research.
- Optional: second character.

## Non-goals
- Not a replacement for Questie/in-game addons (no maps with every mob).
- No accounts, no backend, no sharing.
- No scraping of Wowhead at scale; link to it instead.
- No auto-generated "facts" without sources.

## Data model (sketch)

```
Fact metadata (on every game record):
  sources: [{ name, url, checkedOn }]
  confidence: "in-game-verified" | "multi-source" | "single-source" | "conflicting" | "classic-only"
  conflicts?: [{ claim, sources }]
  notes?

data/quests/<id>.json   { id, title, level, reqLevel, faction, zone, giver, turnIn, objectives, chain, tips, ...meta }
data/dungeons/<slug>.json { name, ranges:[{min,max,source}], entrance, access, quests, bosses, knownIssues, ...meta }
data/class/paladin.json { rotation, macros, talentPlans, trainerRanks, ...meta }
data/professions/<name>.json { ranks, routes:[{source, steps}], campObjects, ...meta }

User state (IndexedDB):
  snapshots[]  (parsed export + raw text)
  questNotes{questId: {note, pinned, abandonedReason}}
  factReports[]
  settings
```

## Quality bar
- Parser tests pass on both samples; diff test 27 → 30 shows the expected changes (level, weapon swap, quests, BS 113 → 133, Mining 126 → 146, guild joined).
- Data schema validation in CI: every record has sources + confidence.
- Lighthouse PWA installable; usable at 375 px wide; dark mode.
